# Diagram standard — lock this in

When the word is diagram, this is the object. Not a mermaid sketch. Not neon rainbow. Not garbled statute posters.

## Look
- Vertical poster. Dark espresso / black.
- Gold, bronze, antique ivory only.
- Hex cubes. Particle streams into a center pedestal.
- Center: lock + leaf. Label GoldTracReceiptV1.
- Gold-lock filter if a photo is used.

## Must print
- PrestigeSF, Inc. · 2026 · goldtrac.org
- Nine fields on the pedestal: kid alg payload_hash chain_root smt_root sig tsa tsa_time app
- Four cubes:
  1. Mint — prestige-mcp --spine — ML-DSA-65 FIPS 204
  2. Bind — SHA-256 SMT + chain tip
  3. Apps — prestige-mcp deadlinesf billrosetta bopcart
  4. Verify — verify-chain + goldtrac.org/verify.html — SOFTWARE NOT_CLAIMED 140-3
- Footer: One signer. One schema. A wrap with sig null is not a leaf.
