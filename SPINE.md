# Spine rules (from this project, not a slogan)

1. One receipt schema for every vertical.
   Same fields every time: kid, alg, payload_hash, chain_root, smt_root, sig, tsa, tsa_time, app
   (prestige-mcp | deadlinesf | billrosetta | bopcart).
   If BillRosetta mints a different shape than MCP, the spine is a story again.

2. Dual-sign only where claimed.
   Live path is ML-DSA-65. Do not advertise ECDSA-P256 + ML-DSA-65 if the mint path is lattice-only.

3. Key custody a fund or a clinic can survive.
   v0: software seed. For money and court files: seed off the app server, sign behind enclave or HSM, rotation, published revoke list.
   Witness already says SOFTWARE, NOT_CLAIMED. Walk through that door on purpose.

4. DeadlineSF must mint the same receipt.
   A CA packet that is only hashed HTML plus an attorney letter is not GoldTrac.
   The compliance PDF carries the same kid as the MCP tool call.

5. Verify as a public act.
   Paste a receipt. Fetch witness. Pass/fail. That page is the product.
