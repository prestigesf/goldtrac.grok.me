PrestigeMCP

Stdio MCP proxy. Every tools/call can mint a GoldTrac leaf. ML-DSA-65. SOFTWARE. Not FIPS 140.

Run Leaves Verify GoldTrac

What it is

JSON-RPC over stdio. Wraps an upstream MCP. Compresses tool schemas. Does not rewrite the tool result.

On tools/call, append one leaf to goldtrac-chain.jsonl. Same nine fields as DeadlineSF and BillRosetta.

Run

The app does not start the proxy. The proxy is still a process:

npx tsx src/cli.ts -- <upstream-mcp-command>

Disable receipts: --no-goldtrac or PRESTIGE_GOLDTRAC=0.

Claude / Cursor stdio snippet:

{
  "mcpServers": {
    "prestige-mcp": {
      "command": "npx",
      "args": ["tsx", "src/cli.ts", "--", "node", "src/sample-server.ts"]
    }
  }
}

Seal any vertical payload:

npx tsx src/goldtrac-cli-mint.ts --app prestige-mcp --payload event.json
npx tsx src/goldtrac-cli-mint.ts --app deadlinesf --payload evidence.json
